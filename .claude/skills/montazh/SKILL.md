Монтаж вертикального Reels с говорящей головой из видео с телефона - вырезать паузы и дубли, сделать субтитры по словам, собрать 9:16 MP4. Используй, когда просят смонтировать видео, болталку, рилс, сделать субтитры или вырезать паузы.
Монтаж Reels
Ты монтируешь короткое вертикальное видео (Reels, TikTok, Shorts) с говорящим человеком. Работаешь в облаке: всё делаешь через ffmpeg и Python, готовый файл кладёшь в репозиторий.

1. Получить видео
Ссылка на Google Диск: gdown --fuzzy "<ссылка>" -O input/source.mp4
Если gdown не скачал, скажи, что файл нужно открыть по ссылке для всех («Все, у кого есть ссылка»).
Файл уже лежит в репозитории: бери его из папки input/.
Проверь видео: ffprobe (длина, размер кадра, есть ли звук).
2. Вырезать паузы
Найди тишину: ffmpeg -i input/source.mp4 -af silencedetect=noise=-30dB:d=0.5 -f null -
Оставь кусочки речи. Вокруг каждого оставь по 0.1 сек запаса, чтобы слова не обрезались.
Если человек повторил одну и ту же фразу (дубль), оставь последний вариант. Дубли ищи по тексту после расшифровки (шаг 3).
Склей куски без перекодирования звука вразнобой: одной командой через filter_complex (trim + atrim + concat).
3. Субтитры
Расшифруй речь: faster-whisper, модель small, word_timestamps=True. Язык укажи явно, если знаешь (ru или kk), иначе автоопределение.
Разбей текст на фразы по 2-4 слова, не длиннее 1.5 сек на экране.
Сделай файл .ass:
шрифт крупный и жирный (DejaVu Sans Bold, размер ~70 при ширине 1080),
белый текст с чёрной обводкой 4-5 px,
позиция: нижняя треть кадра, но выше 300 px от низа (там интерфейс Instagram),
1-2 главных слова во фразе выдели жёлтым ({\c&H00D7FF&}).
Покажи пользователю текст расшифровки и спроси, есть ли ошибки, ТОЛЬКО если он попросил проверку. Иначе сразу монтируй.
4. Собрать финал
Формат: 1080x1920, 30 fps, H.264, звук AAC 128k.
Если исходник не 9:16, обрежь по центру (crop), не растягивай.
Наложи субтитры: -vf "ass=subs.ass".
Громкость выровняй: loudnorm=I=-14:TP=-1.5.
Файл должен быть меньше 90 МБ (иначе GitHub не примет). Если больше, увеличь -crf (23 → 26 → 28).
5. Отдать результат
Сохрани в output/<имя>_montazh.mp4.
Исходник и временные файлы НЕ коммить (они тяжёлые): только папку output/.
Сделай commit и push.
Коротко напиши пользователю: сколько секунд было и стало, сколько пауз вырезано, где лежит файл.
